## Decisions taken

- Drafted COPY issue 2 under the founder's explicit authorization, dated and
  marked for architect review, with strict package parity and no user-facing
  em dash. Small existing Feed/X-ray copy consumers were aligned with main's
  D30 keys; their visual design was not changed.
- Added only necessary experience contracts: multipack/pre-sign callbacks and
  results, progress callbacks, public view props, and selection-specific
  executable Feed back values. Existing components, tokens and motion are reused.
- Unknown or stale prices never become executable values. Feed back asks for
  a generic explicit confirmation if an exact quote is unavailable. Sell shows
  only its own payout. Withdraw/Close amounts come from complete confirmed receipts.
- Optional automatic Settle discovery uses the existing HTTP timeout and
  transaction batch limit. A failed optional read/simulation does not hide the
  owner action. Wallet cancellation or an ambiguous signed submission stops
  further signing until reconciliation; no blind retry.
- P2 builders are used without inventing CU measurements. Provider and service
  failures retain direct RPC exits. No new economics, dependencies or program edits.
- The browser config projection handles main's added public M4.1 imports and
  preserves the authoritative cluster selector's results and refusal reasons.
  Rebuild and rerun against the merged SDK and its exact program artifact.
